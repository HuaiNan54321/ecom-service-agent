# 第14章：检索改进

```bash
python -m examples.ch14.demo
```

从 ecom-service-agent 仓库根目录运行，使用 Python 3.11 或以上。此演示只依赖标准库和第13章的词袋编码器，不联网。

输出依次展示：未过滤时P00领先、过滤过期资料后P01领先；两个预设排名的RRF融合；错误店铺过滤导致零候选；构造的相关集合上的Precision@2和Recall@2。Precision@k固定用k作分母，返回不足k条的位置按未命中计算。

片段、排名和重排规则均为机制教学数据，不是BM25、真实语义Embedding或神经重排器的测评成绩。脚本包含过滤、融合、重排缺失候选和不足k条的边界断言。
